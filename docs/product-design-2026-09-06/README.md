# PureMail 前端体验改造

日期：2026-09-06。直接改造现有 Vue 应用，保留 Win95、浅色、深色三种主题和原有邮件接口。

## 打开预览

在 `mail-vue` 目录运行：

```powershell
node node_modules/vite/bin/vite.js --mode dev --host 127.0.0.1 --port 4317 --strictPort
```

预览复用真实组件，使用 70 封收件邮件、14 封已发送邮件的合成数据。所有 API 请求由开发入口的 Axios adapter 在本地响应；发送和删除也只影响本次预览内存。刷新会重置邮件数据。主题、列表宽度及原有本机草稿使用此预览地址的浏览器存储。

该入口只在开发模式使用。正式构建没有包含预览 HTML、示例数据或模拟 API；正常入口继续使用原有路由和真实接口。

## 已实现

1. **统一布局与主题**：集中定义背景、边界、间距、圆角、选中与未读颜色；统一顶部栏、导航和个人设置。经典窗口扩大到适合阅读的比例，身份卡默认置于主窗口后，可主动唤起。
2. **并排阅读**：收件箱、星标和已发送支持列表与正文并排。按工作区实际宽度切换，列表可拖动、用方向键调整宽度，偏好会保存。折叠阅读区或缩小屏幕后，当前邮件继续打开。
3. **列表层级**：区分未读、当前阅读、复选与星标；验证码缩为次要信息；搜索改为一行，提交后展示范围和数量。手机首封邮件顶部从基线约 250px 提前到 158px。
4. **连续阅读**：上一封／下一封遵循当前已加载列表的排序；地址携带当前邮件，刷新可以恢复；重复点击当前邮件不会清空正文。收件人详情可展开，附件保留独立下载入口，正文底部提供回复和转发。
5. **正文可读性**：更清晰的标题、行距和留白；HTML 宽邮件支持适应宽度与原始大小，原始大小可横向滚动。继续使用原有 HTML 清洗与外部图片许可机制，并解释图片被阻止的原因。深色主题保留独立的邮件纸面以兼容发件方颜色。
6. **写信体验**：多地址粘贴、重复地址去重、非法收件人和空主题的就近错误提示；手机工具栏通过“更多”展开；写信窗口响应 visualViewport。保留原有本机草稿恢复、发送状态、防重复提交和失败重试。
7. **键盘与连接反馈**：`/` 搜索、`C` 写信、`J/K` 连续阅读、`Esc` 返回；列表方向键与 Enter；快捷键帮助；隐藏侧栏不参与键盘焦点顺序；离线／重新联网提示，列表可主动重新加载并保留已有数据。
8. **持续维护材料**：新增使用真实控件的组件展示页、交互回归测试和本次截图；没有新增生产页面或额外依赖。

## 验证

- Vitest：23 个测试文件、169 项测试通过。包含分栏尺寸、窄屏直达、关闭阅读、URL 参数、收件人解析、关闭弹窗后的快捷键、离线恢复，以及原有会话隔离、HTML 安全、附件、草稿和发送回归。
- 正式构建：`node node_modules/vite/bin/vite.js build --mode release` 通过。
- `git diff --check` 通过；检查正式产物没有预览数据。
- 浏览器实际检查：三主题、搜索、相同邮件重复打开、上一封／下一封、刷新恢复、分栏关闭再打开、分隔条键盘调整、宽邮件原始大小、空邮箱、失败后重试、手机写信、非法地址校验、本机草稿恢复和模拟发送。
- 屏幕尺寸：320×740、390×844、768×1024、1024×900、1440×1000。上述检查没有页面级横向溢出；宽 HTML 邮件的局部横向滚动是有意保留的功能。

## 范围与限制

后端接口未扩展：全文检索、高级筛选、云端草稿同步、真实回收站／撤销删除、发送 CC/BCC 仍需独立的接口与数据设计。当前搜索明确显示原有发件人和主题范围，草稿明确标注保存于本机，未为这些能力添加空壳按钮。

本次浏览器验收在桌面 Chromium 的不同视口完成；真实 iOS／Android 键盘、系统屏幕阅读器以及真实服务端收发尚未验收。没有做全站 WCAG 认证或真实网络性能基准，不声明已达到相关认证或性能指标。

构建仍报告大于 500KB 的分包和过期的 Browserslist 数据警告；依赖更新与进一步拆包可单独处理。本次没有部署、推送或发送真实邮件。
