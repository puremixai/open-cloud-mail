# 身份卡 UI 优化

保留票据正面与银行卡背面，完成本轮七项细节优化及重新打开后的状态持久化修复。

- 姓名圆章移至品牌左侧，右侧操作区独立预留空间，统一按钮对齐。
- 正面重新分配品牌、邮箱、ID、撕票线与底部文案的间距和字号。
- 背面提高次要文字可读性，扩大姓名可用空间，弱化文字背后的装饰。
- 两面复用邮箱操作组件，分开处理前缀与域名省略；长品牌名补齐省略号。
- 复制按钮原位显示成功，1.5 秒后恢复；完整地址浮层支持选中和手动复制，失败时直接打开并解释原因。
- 卡片采用 Pointer Events 与指针捕获，支持鼠标及触屏；按钮不启动拖动，卡片仅在拖动时缩放。
- 按实际桌面与卡片尺寸约束位置，恢复保存位置、调整窗口或触屏尺寸后重新校正，避开任务栏。
- 翻面文案区分查看正面/背面，隐藏面不可聚焦；保留减少动画支持，浮层 Escape 关闭后归还焦点。
- 从桌面图标重新打开时清除关闭标记，刷新后继续显示。

卡片从 `frame.vue` 提取至 `src/layout/win95/idcard.vue`，两面共用 `idcard-email.vue`。

## 验证

- 前端 Vitest：20 个文件、156 项通过，包括新增的 7 项行为回归测试。
- 生产构建通过；仍有项目已有的大分包与 Browserslist 数据过期提示。
- 浏览器使用本地 Vite 和合成身份数据，检查桌面正反面，320×640、320×480 与 640×320 触屏模拟视口。
- 实测复制成功、剪贴板拒绝、长英文邮箱/姓名/站点名、浮层焦点与 Escape、触屏拖动、边界约束、关闭再打开并刷新、减少动画模式。
- 320×640 下卡片为 304×240；拖到最底部时卡底 584px，桌面底部 592px，保留 8px 间隙。640×320 横屏时卡底 264px，桌面底部 272px。
- 手机为浏览器模拟，未进行真机验证。本次未部署。
