# UI / UX 修改与验收记录

实施日期：2026-09-05 至 2026-09-06。分支：`codex/ui-ux-polish`。本记录对应原审查报告，经用户“开始修改”后实施。代码保留在工作区，未提交、推送或部署。

## 已完成

- 统一主要操作的本地 SVG 图标按钮、可访问名称、键盘焦点、按下/选中/禁用/忙碌反馈；保留 Win95 外观，完善桌面菜单键盘操作与危险操作语义。
- 调整主题颜色、文字对比度、错误消息换行、减少动态效果偏好。修正组件库延迟加载覆盖主题变量的问题。
- 登录页立即提供表单，补充持久标签、自动填充、密码显隐、字段错误与焦点定位，修正域名选择框偏移。
- 邮件列表按实际容器宽度调整行布局，虚拟滚动与紧凑/舒适行高一致；补齐选择数量、95 封上限、加载/错误/空状态；刷新保留已有内容，修正删除后的总数。
- 新增当前邮箱的服务端搜索，匹配发件人名称、地址和主题，列表与总数使用同一过滤条件；保留归属、邮箱、类型、删除标记与游标约束，转义 LIKE 通配字符。
- 邮件详情与附件操作使用明确的按钮名称和处理中反馈；保留侧栏的用户选择。
- 写信关闭提供“继续编辑 / 放弃修改 / 保存草稿”；按用户与邮箱隔离保存本机恢复记录，包含附件，显示保存/失败/重试状态；刷新后可恢复，手动删空会清理旧恢复记录。
- 发送过程中保留编辑界面并锁定修改，区分提交中与提交成功；持久化失败时保留内容并阻止开始发送，读取附件时阻止发送和保存；不确定发送重试保留原请求标识，切换账户后的旧回调不能覆盖新界面。
- 编辑器初始化增加超时、错误、重试与生命周期保护；主题切换保留正文，插入图片使用可持久化数据。

## 验证

| 检查 | 结果 |
| --- | --- |
| 前端 Vitest | 19 个文件，149 项通过 |
| Worker Vitest | 17 个文件，139 项通过，含 9 项实际 SQLite 搜索测试 |
| 生产构建 | 通过；保留现有大于 500 kB 分包与 Browserslist 数据过期提示 |
| Git 差异格式检查 | 通过；仅 Windows LF/CRLF 提示 |
| 浏览器外观 | Win95、现代浅色、现代深色；桌面及 390×844 手机模拟视口 |
| 浏览器写信流程 | 自动保存提示、刷新后恢复主题、关闭三选项、保存后关闭已实测 |
| 手机布局 | 登录、收件箱、写信与关闭弹窗无页面横向溢出；写信操作与保存状态可见 |

服务端复测命令：`node node_modules/vitest/vitest.mjs run --config vitest.unit.config.js`。`pnpm test` 的自动依赖安装曾遇到 Windows EPERM 重命名错误，因此使用已有本地测试运行器完成验证；依赖清单和锁文件未修改。

浏览器使用本地 Vite 和临时合成邮件 API，未访问真实邮箱内容，也未发送真实邮件。手机检查为浏览器模拟，不涵盖真机软键盘。恢复数据仅保存在当前浏览器，并非跨设备云草稿。回收站恢复/删除撤销未新增服务端能力，入口明确说明当前不支持恢复。TinyMCE iframe 内 Escape 仍遵循编辑器自身行为，未强行截获。搜索采用 LIKE 子串匹配，未新增全文索引，大规模邮箱性能需按真实数据评估。
